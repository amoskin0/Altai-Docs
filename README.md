# Altai documentation / Документация Altai

Altai is a statically typed language with checked integer arithmetic, boolean control flow, functions, byte input, mutable buffers and explicit results. Its current native target is Windows x86-64. This repository contains user documentation in English and Russian. Altai keywords, code and compiler diagnostics use English.

Altai: язык со статической типизацией, проверяемой целочисленной арифметикой, логическими операциями, функциями, вводом байтов, изменяемыми буферами и явными результатами. Текущая цель генерации машинного кода: Windows x86-64. Здесь находится пользовательская документация на английском и русском. Ключевые слова Altai, код и диагностика компилятора используют английский язык.
