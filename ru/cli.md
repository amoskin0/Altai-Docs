# Справочник команд

[Содержание](../README.md#русский) · [English](../en/cli.md)

Ниже `altai` обозначает официальный исполняемый файл командной строки. В PowerShell для файла в текущем каталоге используется `.\altai.exe`. Пути с пробелами заключаются в кавычки. Команды и сообщения компилятора используют английский язык.

```text
altai tokens <source.alt>
altai tree <source.alt>
altai check <source.alt>
altai run <source.alt>
altai build [--target <name>] <source.alt> <output>
altai targets
altai help
```

| Команда | Результат |
| --- | --- |
| `tokens` | Лексические токены с диапазонами и позициями; не проверяет всю семантику языка |
| `tree` | Синтаксическое дерево программы; не заменяет проверку типов и имён |
| `check` | Полная статическая проверка, включая тела всех функций, пути возврата и ограничения ресурсов; без эффектов программы |
| `run` | Полная проверка, затем интерпретируемое исполнение |
| `build` | Полная проверка, затем генерация исполняемого машинного кода; обычные выражения исходника не выполняются |
| `targets` | Зарегистрированные цели и доступность их реализации |
| `help` | Использование команд |

Вход использует строгий UTF-8 и [спецификацию языка](specification.md). Назначение `build` должно быть новым: существующие файлы отклоняются. Явная цель выбирает выходную платформу, а не другой язык. По умолчанию используется цель платформы компилятора; неподдерживаемое значение по умолчанию приводит к ошибке. Реализована только генерация `windows-x86_64`.

```powershell
& "C:\Altai Tools\altai.exe" run "C:\My Project\hello.alt"
```

## Коды завершения

| Код | Значение |
| --- | --- |
| 0 | Успех |
| 1 | Статическая ошибка исходного текста |
| 2 | Ошибка инструмента или ввода-вывода |
| 3 | Арифметическая ошибка или выход индекса байтов за границы при исполнении |

Статическая диагностика содержит файл, строку, столбец, код, сообщение, ограниченный фрагмент исходного текста и контекстную подсказку, где она применима. Некорректный UTF-8 сообщает смещение в байтах. Диагностика времени исполнения не содержит позиции исходного текста и использует следующие точные строки stderr:

```text
A0401: int64 overflow.
A0402: division by zero.
A0403: byte index out of bounds.
```

Каждая строка завершается LF. Поздняя ошибка времени исполнения сохраняет предыдущий успешный вывод. Статическая ошибка предотвращает любое исполнение и создание исполняемого файла. `check` и `build` принимают обычное `print(1 / 0)`, поскольку это операция времени исполнения; `const x = 1 / 0` отклоняется при проверке. Ошибка записи stdout останавливает исполнение с кодом 2; неудачная запись диагностики сохраняет код 3 и может оставить частичное сообщение.

Ошибки открытия файла, выделения памяти и лимитов на уровне программы являются значениями для `match`, а не автоматическими кодами завершения процесса. `read_file` выполняется только в `run` или готовом исполняемом файле, но не в `check` или `build`. Относительные пути разрешаются от рабочего каталога процесса; файловые операции имеют обычные права ОС и могут ожидать завершения ввода. Коды ошибок от 1 до 7 описаны в [спецификации](specification.md).
