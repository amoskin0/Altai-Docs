# Начало работы

[Содержание](../README.md#русский) · [English](../en/getting-started.md)

Файлы Altai имеют расширение `.alt` и кодировку UTF-8. Ключевые слова используют английский язык. Эта инструкция описывает текущий инструмент командной строки для Windows x64. Сборка компилятора из исходников не требуется.

## Первая программа

Сохраните следующий текст в `hello.alt` в каталоге, где можно создавать файлы:

```text
print("Hello, world!")
```

Если официальный инструмент командной строки находится в этом каталоге, откройте там PowerShell:

```powershell
.\altai.exe check .\hello.alt
.\altai.exe run .\hello.alt
```

`check` проверяет всю программу без исполнения. `run` сначала проверяет её, затем интерпретирует. Программа выводит `Hello, world!` и перевод строки. Статическая ошибка даже в поздней инструкции может предотвратить исполнение всей программы.

## Отдельный исполняемый файл

```powershell
.\altai.exe build --target windows-x86_64 .\hello.alt .\hello.exe
.\hello.exe
```

Выберите новый выходной путь: `build` не заменяет существующие файлы. Команда проверяет программу, но не выполняет обычные выражения. Полученный файл работает в Windows без исходника, инструмента Altai и компилятора C. Реализована только генерация машинного кода для Windows x86-64. См. [целевые платформы и поведение машинного кода](native.md).

## Переменные, константы и функции

```text
const quantity = 3
var price = 120
price += 5
print(price * quantity)

fn is_digit(code: int64) -> bool {
    if code < 48 {
        return false
    }
    return code <= 57
}

print(is_digit(53))
```

Результат: `375`, затем `true`. `var` объявляет инициализированную изменяемую привязку. `const` объявляет целочисленную или логическую константу, вычисляемую при проверке. `=` обновляет только существующую изменяемую привязку. Типы фиксированы, условия требуют bool. Типы параметров и результата функции задаются явно; значения параметров неизменяемы. Вызовы требуют круглых скобок. Инструкции разделяются переводами строки без точек с запятой.

## Циклы и байты

```text
var data = bytes("Altai")
var index = 0
var total = 0
while index < len(data) {
    total += data[index]
    index += 1
}
print(total)
```

Программа выводит `491`. `len` считает байты UTF-8, а не символы. Индексированный байт имеет тип int64 и значение от 0 до 255. Индексы проверяются во время исполнения. Содержимое неизменяемо; файловый ввод и изменяемые буферы описаны ниже. [Спецификация](specification.md) определяет порядок вычислений, ошибки и ограничения ресурсов.

## Altai Editor

Altai Editor открывает, редактирует и сохраняет `.alt` файлы. F5 сохраняет активный документ и запускает интерпретатор; Shift+F5 останавливает его. F5 не запускает сборку машинного кода. Интерфейс поддерживает английский и русский языки. Ключевые слова и диагностика компилятора остаются английскими.

Проверку токенов и дерева описывает [справочник команд](cli.md), а поддерживаемое подмножество: [возможности и ограничения](features.md).

## Файлы и буферы

`read_file(bytes("input.alt"), 1048576)` возвращает `result<bytes>`: ветвь `ok(source)` получает неизменяемые байты, а `err(code)` получает код ошибки int64. Содержимое файла сохраняет NUL и некорректный UTF-8. Сам путь должен быть непустым корректным UTF-8 без NUL. Относительные пути разрешаются от рабочего каталога процесса с обычными правами ОС.

```text
match read_file(bytes("input.alt"), 1048576) {
    ok(source) { print(len(source)) }
    err(code) { print(code) }
}
```

`buffer(limit)` возвращает `result<buffer>`. `append_byte(output, value)` возвращает `status`; его ветви записываются как `ok { ... }` и `err(code) { ... }`. `snapshot(output)` возвращает `result<bytes>` с независимой неизменяемой копией. Присваивания буфера разделяют хранилище; снимок не меняется при изменении буфера. `len` и проверяемая индексация принимают bytes и buffer.

```text
match buffer(2) {
    ok(output) {
        match append_byte(output, 65) {
            ok {
                match snapshot(output) {
                    ok(copy) { print(copy[0]) }
                    err(code) { print(code) }
                }
            }
            err(code) { print(code) }
        }
    }
    err(code) { print(code) }
}
```

Пример с буфером выводит `65`. Память освобождается автоматически. Обе ветви match обязательны, сначала `ok`, затем `err`. [Спецификация](specification.md) определяет типы, коды ошибок и владение.

Управляемое хранилище ограничено 16 МиБ на объект, 4096 живыми объектами и 64 МиБ дескрипторов и ёмкости данных с учётом пиков роста. Это не лимиты всей памяти процесса или времени исполнения. Файловый доступ не является песочницей и не имеет ограничения времени ожидания.
